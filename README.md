# Gym-Bo

Tracker gratuito per palestra, cardio, dieta e corpo, in italiano. Funziona dal browser e si installa sul telefono come app (PWA), anche offline.

**App:** https://edoardobassani.github.io/Ghisa/

## Gratis, per sempre

Gym-Bo è gratuito e lo resterà: nessun abbonamento, nessun pagamento, nessuna pubblicità, nessun account. I dati restano sul telefono di chi lo usa (e sul suo Google Drive, se attiva il backup).

Se qualcuno ti chiede soldi per Gym-Bo, o per una sua copia, non è la versione originale.
